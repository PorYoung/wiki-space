## 修复 ActivityPage 进入即白屏（2026-09-10）
- 根因：`/projects/:id/activity` 整页消失（React 树整体卸载）。`GET /api/v1/activities` 返回的是 activities 表原始行（`actorId/verb/targetType/targetId/targetTitle`），而 ActivityPage 按虚构 DTO（`actor/action/target`）编写，`filteredFeed` 的 useMemo 里 `a.actor.toLowerCase()` 读到 undefined 抛 TypeError。useMemo 不分 subtab 都会计算，所以一进页面、feed 数据一到就崩。
- 修复：① server routes.ts activities 列表改显式 select + leftJoin users 补 `actorName`（顺带修好 Dashboard 动态操作人恒显「系统」的隐性 bug）；② ActivityPage 改用真实字段：verb→中文（VERB_TEXT，与 DashboardPage 一致）、actorName（null 兜底「系统」）、targetTitle；筛选 chips 按 verb 映射（comment/sync/publish/edit|create|delete），搜索判空。
- 注意：verb 还有 `ai_classify` 等未映射值，走 `?? item.verb` 原样显示、filter 归入 all。
- 验证：web/server tsc 均通过；curl 登录 admin@ewiki.local 实测 /api/v1/activities 已返回新结构（actorName 正确带出「ewiki 管理员」）。
- 教训：ewiki 后端列表接口习惯性返回 drizzle 原始行，前端新页面务必先 curl 一把真实响应再定 interface，别凭界面想象写 DTO。
