# 读者视角产品设计方案：搜索与阅读体验

> 版本：v0.1
> 日期：2026-09-13
> 状态：设计稿
> 关联：PRD 全局文档库 / 搜索 / 发布站点

---

## 产品定位

ewiki 存在两种完全不同的使用视角，对应两套独立的页面体系：

| 视角 | 用户画像 | 核心诉求 | 页面体系 | 入口 |
| --- | --- | --- | --- | --- |
| **读者 / 搜索者** | 团队成员、访客、外部用户 | 找到答案、快速阅读、获取知识 | 首页 → 搜索结果 → 文档阅读 | `/` 、`/search`、已发布站点 |
| **维护者 / 管理员** | 项目 Owner、Maintainer、Editor | 管理知识、编辑内容、配置项目 | 仪表盘 → 项目管理 → 编辑 | `/dashboard`、`/projects/*` |

当前产品只有维护者视角。本方案补齐读者视角，让产品从"知识库管理工具"演进为"知识获取与发现平台"。

---

## 设计原则

1. **内容优先**：搜索结果和阅读页面去除一切管理干扰，让内容成为绝对主角
2. **搜索即入口**：用户带着问题来，3 秒内看到相关结果，1 次点击进入阅读
3. **渐进式交互**：从关键词搜索 → 语义搜索 → AI 问答，体验平滑演进
4. **传播友好**：好的内容容易被分享，URL 结构清晰、页面有摘要预览
5. **阅读愉悦**：排版、间距、字体层级经过打磨，长文阅读不累

## 信息架构

```
读者视角（Reader）
├── /                    首页（搜索框 + 推荐/最近）
├── /search?q=xxx        搜索结果页
│   ├── Tab: 文档 / 项目 / 站点
│   ├── 筛选栏（项目、时间、类型）
│   └── 结果列表（带摘要高亮）
├── /read/:id            文档阅读页（纯净阅读模式）
│   ├── 文章内容
│   ├── 目录导航（悬浮）
│   └── 相关推荐
└── /sites/:slug         已发布站点（已有，只读）

维护者视角（Maintainer）—— 现有体系不变
├── /dashboard           仪表盘
├── /library             文档库（管理视图）
├── /projects/:id/*      项目管理 + 编辑
└── ...
```

两个视角通过右上角用户菜单的"管理控制台"切换，从读者进入维护者。

## 搜索结果页设计

### 页面结构

```
┌─────────────────────────────────────────────────┐
│  ewiki logo  [  搜索框 🔍   ]   主题/通知/用户  │
├─────────────────────────────────────────────────┤
│  找到 128 个结果 · 用时 0.2s                    │
│  ┌─────┐ ┌─────┐ ┌─────┐                      │
│  │ 文档 │ │ 项目 │ │ 站点 │  —— Tab 切换       │
│  └─────┘ └─────┘ └─────┘                      │
├──────────────┬──────────────────────────────────┤
│  筛选侧栏     │  结果列表                        │
│              │                                  │
│  📁 项目      │  📄 文档标题（匹配词高亮）       │
│  ▢ 全部      │  文档摘要...匹配词...匹配词...   │
│  ▢ 项目A     │  项目名 · 2分钟前 · 1.2k 字      │
│  ▢ 项目B     │                                  │
│              │  📄 下一条结果...                │
│  🕐 时间      │  ...                            │
│  ▢ 今天      │                                  │
│  ▢ 本周      │  分页 / 加载更多                 │
│  ▢ 本月      │                                  │
│              │                                  │
│  📄 类型      │                                  │
│  ▢ Markdown  │                                  │
│  ▢ PDF       │                                  │
│  ▢ 图片      │                                  │
└──────────────┴──────────────────────────────────┘
```

### 交互细节

- **搜索框常驻顶部**：滚动时搜索框收起为紧凑模式，可随时修改关键词
- **结果卡片**：标题 + 摘要（关键词高亮）+ 所属项目 + 更新时间 + 字数
- **键盘导航**：↑↓ 选择结果，Enter 打开，Esc 聚焦搜索框
- **空状态**：无结果时展示"换个关键词试试" + 热门搜索推荐
- **搜索建议**：输入时下拉展示历史搜索 + 热门搜索 + 实时建议

### Tab 设计

| Tab | 内容 | 卡片样式 |
| --- | --- | --- |
| **文档** | 匹配到的文档列表 | 标题 + 摘要高亮 + 项目 + 时间 |
| **项目** | 名称/描述匹配的项目 | 项目卡片 + 文档数 + 成员数 + 最近更新 |
| **站点** | 已发布的公开站点 | 站点封面 + 描述 + 访问量 + 直达链接 |

## 文档阅读页设计（纯净模式）

### 页面结构

```
┌─────────────────────────────────────────────────┐
│  ← 返回  ewiki · 项目名 / 路径           🔊 ⤴  │
├─────────────────────────────────────────────────┤
│              文章标题（大号字）                   │
│              作者 · 2026-09-13 · 8 分钟阅读     │
│                                                   │
│  ───────────────────────────────────  📑 目录   │
│  正文内容...                                    │  │
│  ...                                            │  │
│  ...                                            │  │
│  ...                                            │  │
│  ...                                            │  │
│  ...                                            │  │
│                                                   │
│  ─────────────────────────────────────────────── │
│  标签：#标签1 #标签2                              │
│  👤 编辑历史 · 💬 评论 · 🔗 分享                 │
│                                                   │
│  ─── 相关推荐 ──────────────────────────────── │
│  📄 相关文档 A          📄 相关文档 B           │
│  📄 相关文档 C          📄 相关文档 D           │
└─────────────────────────────────────────────────┘
```

### 阅读体验要点

- **宽幅留白**：正文最大宽度 720px，左右留白减少视觉压力
- **字体层级**：标题 32px / 副标题 20px / 正文 17px / 注释 14px
- **行间距**：正文 1.8 倍行高，段落间距 1.5em
- **目录悬浮**：右侧滚动时高亮当前章节，点击跳转
- **阅读进度**：顶部细进度条，显示阅读百分比
- **深色模式**：与系统一致，正文采用低对比度深色背景

## AI 问答演进路径

搜索页不是终点，而是 AI 知识助手的入口。分三阶段演进：

### Phase 1：关键词搜索（当前）
- 传统全文检索，结果列表展示
- 后端：PG ILIKE → 迁移到 Meilisearch
- 体验：快、准、稳定

### Phase 2：语义搜索 + AI 摘要
- 搜索结果顶部展示 AI 生成的"答案摘要"
- 基于 Top N 结果的内容合成回答
- 标注引用来源，可跳转原文
- 交互：搜索框输入 → 结果页顶部出现 AI 摘要卡片 → 下方是传统结果列表

### Phase 3：对话式 AI 助手
- 搜索框变为对话框
- 支持多轮追问
- 上下文记忆（同一会话内）
- 可直接引用文档片段生成回答
- 支持"基于这个项目回答"等范围限定
- 交互：类 ChatGPT 界面，左侧会话列表，右侧对话区域，消息中嵌入文档引用链接

### 统一的搜索框演进

```
Phase 1                Phase 2                  Phase 3
┌──────────┐         ┌──────────┐             ┌──────────┐
│ 🔍 搜索...│        │ ✨ 问点什么...│         │ 💬 对话...│
└──────────┘         └──────────┘             └──────────┘
   ↓ 回车               ↓ 回车                  ↓ 回车
 结果列表             AI摘要 + 结果列表         对话式回答
```

## 技术实现要点

### 后端
- 全局搜索 API `/api/v1/documents` 增加 `q` 参数支持（服务端 ILIKE 搜索）
- 搜索结果增加 `snippet` 字段（关键词前后文摘要）

### 前端
- 新增 `SearchPage.tsx`：独立的搜索结果页面，不进入管理 Layout
- 新增 `ReaderTopBar.tsx`：读者视角统一顶栏组件
- 首页搜索 form 提交跳转 `/search?q=xxx`
- 路由：`/search` 路由在 Layout 之外，使用 RequireAuth 包裹

### 设计规范
- 沿用现有 CSS 变量和组件类
- 圆角、阴影、间距与现有体系一致
- 深色模式自动适配
